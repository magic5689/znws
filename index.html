知识可编辑

编译出来的页，人能改

Wiki 页不是一次生成的死文档：定义可以改、别名可以补、冲突可以标，每次修订进版本链，可对比、可回滚。

  • 改定义正文分句编辑，保存即生效，检索按新版本走
  • 补别名把业务口语并进概念，问法不用改
  • 标冲突两份文档说法不一致时挂起，等人裁定而非硬答
  • 版本链v1 → v4 全留痕，随时回退到任意版本

Agent 居中，接网关与 Skill

向下通过 MCP 网关调存量系统，向外通过 Skill 库调一切可编排的能力——开放连接一切外部系统，系统不用改造。

Agent 在中间

问数型、问答型或 2–8 个混合编排，由它判断这次该调数据、调文档，还是两边一起调。

向下：MCP 网关 → MCP 服务

存量系统包一层 MCP Server，经网关统一暴露，零改造接入，密钥与工具清单集中在网关。

向外：Skill 库 → 每个 Skill 文件夹

图表、文档、PPT、知识管理按需安装，也能上传自建；一个 Skill 就是一个独立目录，放什么能力就调什么能力。

一切外部系统，同一条链路

数据库、报表、业务系统、第三方 API，只要能包成 MCP 或写成 Skill，Agent 都能调。

ASK BACK

能答就答，要反问也只问两轮

除了确实无权限，一律先给已知结论，不空回、不装傻。信息不足时反问补全，硬性限制在两轮内。

追问 · 第 1 轮
今年水质怎么样？

先给全省结论：国考断面优良率 96.8%，同比 +1.2 个百分点。

要看哪条流域？岷江沱江嘉陵江

PERMISSION

权限不是异常，是常态呈现

唯一可以"不回答"的场景，且要说清：为什么看不到、谁能看到、怎么申请。

受限问法
给我看全市所有企业的逐条排放明细
需授权 该数据分级为「内部 · 明细级」，授权主体：市局数据管理员 可先看：分行业汇总 / 重点企业清单 / 超标企业名单
永远不用 0 和 — 冒充真实值；看不到也给出去路
SECURITY

数据留在自己机房

全私有化、双库信创，从部署、权限到沙箱，四道防线一条都不靠"静默放行"。

本地可部署✦
